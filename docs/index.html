  4. Grade

    13 fields against the solver, within ₹1. A zero return scores 0.

Three levels

The solver applies Rule 88A set-off with the least cash, checked by brute force.

Easy
Intra-state sales and purchases, CGST and SGST.
Medium
Adds inter-state IGST and nil-rated sales.
Hard
Adds blocked ITC, reverse charge and credit brought forward.

Quick start

Python 3.11+. Baselines need a key in .env.

git clone https://github.com/akshit9162/gst-env
cd gst-env && python3 -m venv .venv
.venv/bin/pip install -e ".[dev,baseline]"
.venv/bin/python -m pytest -q
.venv/bin/python scripts/reward_audit.py --tasks 300
.venv/bin/python scripts/baseline.py \
  --per-difficulty 3 --out results/run.jsonl

What it leaves out

It tests GST computation, not today’s GSTR-1 to IMS to 3B workflow. CA review in progress.
